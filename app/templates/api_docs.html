Method & Path Parameters Description

POST /api/v1/batch { reviews: [{text, rating}] } or CSV file Audits up to 200 reviews concurrently with aggregated spam KPIs and breakdown.
GET /api/v1/models None Returns performance metrics (F1, Accuracy, ROC-AUC) across all evaluated architectures.
